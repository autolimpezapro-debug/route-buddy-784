# Lovable Route Planner

crie um sistema de roterização da seguyinte maneira. irar criar um mapa virtual. todas as exportações de conversas de whatssap possui doc anexos PC- pedido de compra. o sistema irar ler todos os pedidos,empresas, endereços. irar listar todos os pedidos e criar roterição de acordo com os endereços, ter a opção de filtrar por pedido. pedido filtrado e selecionado irar para rota de coleta. os outros podem estar aguardando retirada, estoque, fabricação etc.  nunca duplicar o sistema com as importaçoes mesmo que seja a mesma varias vezes
